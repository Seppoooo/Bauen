# Eigene Blocktexturen (optional)

Der Builder malt alle Texturen selbst (16 × 16 Pixel, Minecraft-ähnlich). Wenn du hier eine PNG-Datei
ablegst, wird sie stattdessen verwendet. Dateiname = Texturname, zum Beispiel:

- `stone_bricks.png`
- `oak_planks.png`
- `grass_block_top.png`, `grass_block_side.png`
- `oak_log.png` (Rinde), `oak_log_top.png` (Stirnseite)

Danach die Liste in `textures.json` ergänzen, z. B. `["stone_bricks", "oak_planks"]`.
Die originalen Minecraft-Texturen darfst du nur für dich selbst verwenden, nicht veröffentlichen.
