# Hyrox Trainingslog

Eine einzelne Seite (`index.html`) zum Eintragen aller Hyrox-Trainingsdaten bis zum Wettkampf (Hyrox @ FIBO, April 2027).

- Club-Workouts (Power, Engine, Endurance …) per Copy & Paste von der Hyrox-Seite übernehmen – Bereich, Titel, Format und Übungen werden automatisch erkannt
- Komplette/halbe Simulationen mit allen 8 Läufen, 8 Stationen und Roxzone
- Läufe (Distanz, Dauer, Pace) und Kraft-Einheiten mit Notizen, Puls und Gefühl
- Countdown, Zielzeit, Bestzeiten je Station inkl. Vergleich zur Ziel-Aufteilung
- Verlaufsdiagramm der Simulationszeiten
- Daten liegen im Browser (localStorage) – Export/Import als JSON für Backups

Öffnen: `index.html` im Browser öffnen oder über GitHub Pages hosten.
