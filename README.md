# Hyrox Tracker

Private Seite (`index.html`) für alle Trainings- und Wettkampfdaten bis zum ersten Hyrox auf der FIBO 2027.

- **Profil:** Name, Alter, Körpergewicht, Größe, Division (Open/Pro/Doubles/Relay), Zielzeit, Countdown
- **Gewichte je Station:** offizielle Gewichte der Division (anpassbar) und eigenes Trainingsgewicht
- **Einträge:** Kurs, Simulation (komplett/halb, alle 8 Läufe, 8 Stationen, Roxzone, Gewicht je Station), Station, Laufen (GPX/TCX-Import von Garmin/Strava), Kraft – mit Puls, Anstrengung 1–10 und Notizen
- **Rekorde:** Bestzeit je Station und je Laufkilometer, beste Simulation/Rennzeit, automatische 🏆-Markierung bei neuem Rekord
- **Auswertung:** Vergleich mit Ziel-Splits (anpassbar), schwächste Station hervorgehoben, Anteil Laufen/Stationen/Roxzone, Entwicklung über die Zeit, Einheiten pro Woche
- **Wettkampf:** offizielle Ergebnisse mit Splits, Platzierung, Finish-Foto und Notizen, Vergleich mehrerer Rennen
- **Kurse (Hyrox Training Club):** Vorlagen von Hand anlegen, Wochenplan, mit einem Klick als Eintrag übernehmen, Vergleich von Woche zu Woche, Kurse pro Monat
- **Export:** CSV, PDF-Bericht, JSON-Backup

Als claude.ai-Artifact ist die Seite privat; die Daten liegen im eigenen Konto und sind auf allen Geräten gleich. Lokal geöffnet wird im Browser gespeichert.
